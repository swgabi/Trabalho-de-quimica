# Trabalho de Química - Níquel (Ni)

Página web desenvolvida para um trabalho escolar de química, apresentando informações sobre o elemento químico níquel.

## Tecnologias
* HTML5
* CSS
* Bootstrap

## Conteúdo do Site
* Informações gerais sobre o Níquel
* Imagem do elemento
* História da descoberta do elemento
* Como ocorreu a descoberta
* Ocorrências do Níquel na natureza
* Uso do Níquel no cotidiano
* Importância ou Riscos do Níquel
* Fontes consultadas
